## Regression boundary

Extend current tabs, dirty-close recovery, hash routing, recents, link generation, context attachments and [panel interaction work](../012-panel-interaction/README.md). That neighboring document was inspected as context; its historical test claims were not revalidated here. The query feature must use existing panel placement logic and must not introduce a second overlay/scrim owner.

The [implementation map](10-implementation-plan.md) names proposed files; proposed file names are not claims that those files exist. Existing notebook-output tests include a NULL-to-empty expectation (identifier search in `tests/test_cellrun.py`); changing shared decoding therefore requires an intentional regression update, not a silent global substitution.
